## Project Overview

This project is designed to update an already exist software used in hospitals like Mercy San Juan. This program refered to as MS4 by the employes while functional is often refered to as ourdated and hard to use. Our project aims to keep the flow and uses of the sofware wile making it more intutive and user-friendly to help making things run smoother and increase productivity.

## Any other relevant information

MS4 or Siemens MedSeries4 allows for the tracking of hospital beds, patient discharges and admissions, printing and finding basic patient info as well as much, much more! Due to the range of services offered by this software our group decided to only takle 3 main areas of this Website, 2 of our group members being near perfessionals who work with the software in their Interships we decided to focus on those areas listed by name above.
